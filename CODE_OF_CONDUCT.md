# Community conduct

Treat contributors and users with respect. Technical criticism should address the work,
include evidence, and allow room for correction. Welcome questions and people with different
backgrounds and levels of experience.

Harassment, threats, discriminatory abuse, sexualized conduct, and publishing another
person's private information are not acceptable in project spaces. Do not use issues or
pull requests for spam or personal attacks.

Maintainers may edit or remove content, close disruptive discussions, or restrict participation
to protect the community. Explain moderation decisions where practical and apply these rules
consistently. Report concerns privately to maintainers through an available repository contact;
if none is configured, request a private contact without posting sensitive details.
